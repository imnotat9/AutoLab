# 🧠 Automaton Simulator (DFA, NFA, e-NFA)

👋 Hi! This is a small project created to tinker with and visually study Finite State Automata (super useful if you're preparing for exams like *Theory of Computation* 📚). 

> 🤖 The code for this app was entirely generated by Artificial Intelligence.

## 🎯 What does it do?
It's a minimal and interactive web app where you can draw your automaton and see *exactly* what happens when you feed it a string. It seamlessly handles:
- **DFA** (Deterministic)
- **NFA** (Non-Deterministic)
- **e-NFA** (Automata with $\epsilon$ moves)

## ✨ Main Features
- 🖱️ **Pure Drag & Drop:** Draw states and transitions in a snap.
- ⌨️ **Fluid UX:** Select, delete with the keyboard, set the start state (with a little arrow) and final states (double circle 🎯).
- 👻 **Epsilon Moves:** Quick button for zero-cost transitions ($\epsilon$).
- 🕹️ **Step-by-Step Simulation:** Watch the automaton "think" step by step, or run the quick simulation to instantly see the result (Accepted/Rejected).
- ⚡ **Zero hassle:** No servers, no builds. Everything is contained within a single HTML file!

## 🚀 How to use it?
Download `index.html` and double-click it to open it in your browser.
